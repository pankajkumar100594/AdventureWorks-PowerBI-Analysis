# AdventureWorks Sales & Profit Analysis | Power BI

## 📊 Project Overview

This project is an interactive **Sales and Profit Analysis Dashboard** built using **Microsoft Power BI** with the AdventureWorks dataset.

The objective of this project is to analyze sales performance, profitability, product performance, customer contribution, geographic performance, and year-over-year growth using interactive Power BI dashboards and DAX measures.

---

## 🎯 Business Objective

The dashboard helps answer important business questions such as:

- How much total sales did the business generate?
- What is the total cost?
- What is the gross profit?
- How are sales performing over time?
- How does the current year's sales compare with the previous year?
- What is the year-over-year sales growth?
- Which areas of the business are performing well?
- How does profitability change over time?
